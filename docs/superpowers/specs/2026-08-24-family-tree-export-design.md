# 族谱/师徒树导出设计

日期：2026-08-24
状态：已与用户确认方案 C（核心逻辑进包 + CLI 入口 + 前置方向修正）

## 背景与目标

知识图谱库（data/novel.db，376 章全量抽取）已含人物"关系"边，attrs 中带性质
（父子 54/母子 17/兄弟 30/夫妻 18/师徒 16/祖孙 9/叔侄 13 等，键名有 `关系`/`性质` 两种）。
用户需要两个导出功能：

1. **李氏族谱树**：从上到下树状，范围=李家血脉+嫁入配偶（司元白等外人不含）
2. **势力师徒树**：任选势力，以成员为中心（含多重所属，如李尺泾同时属李家与青池宗），
   成员的师徒边进树；对方若是外人则作外节点显示（不展开其徒子徒孙）

导出格式：**graphviz 图片（SVG+PNG）与 Mermaid 文本（.md）各一套**。
节点标注：`名字[境界·宗门]`（宗门=所属边中除血脉家族外的拜入门派）。

前置问题：**"关系"边方向无统一约定**（`李通崖→李木田`子→父 与 `李木田→李尺泾`父→子并存，
且有 `任氏→李玄宣`+`李玄宣→任氏` 方向相反的重复边）。必须先修库统一方向，树才能画对，
且修库后 viz 关系边箭头语义（长→幼/师→徒）全局受益。

## 架构（方案 C）

```
scripts/fix_relation_direction.py   一次性方向修正（规则自动判 + 存疑人工核查清单）
novel_kg/trees.py                   纯逻辑：成员圈定 / 树构建 / dot 与 mermaid 渲染
scripts/export_tree.py              CLI 薄入口
tests/test_trees.py                 树构建与渲染单测（内存 sqlite fixture）
data/exports/                       输出目录
```

依赖新增：`graphviz`（python 封装包，调系统 dot；系统 graphviz 15.0 已装）。
dot 缺失时降级只出 Mermaid 并提示。

## 组件设计

### 1. fix_relation_direction.py（前置，一次性）

**方向约定**（落库后的全局约定）：
- 亲子/长幼类（父子、母子、父女、母女、祖孙、叔侄、姑侄、舅甥、族叔侄、后裔）：
  `from=长辈 → to=晚辈`
- 师徒/师兄弟：`from=师 → to=徒`
- 对称类（夫妻、兄弟、兄妹、姐弟、族兄弟、敌对、盟友等）：不动

**判向信号**（优先级从高到低）：
1. **attrs 简介文本**：一方简介含"对方名+之子/之女/之父/之母/之徒/之师/之妻/之兄"式表述，
   直接定向（最强信号）
2. **同辈传递**：兄弟/兄妹边连接 A-B，A 已有定向亲子边定位辈分，B 取同辈
3. **字辈代际表**（最后兜底，仅李家）：木田辈=1 → 湖/崖/平/泾辈=2 → 玄辈=3 → 渊/曦辈=4 →…
   （从已知边归纳，覆盖不到的支系留人工）
4. 首现章节早者辈分高：仅弱提示，**不自动落库**，进核查清单

**落库动作**：交换 from_id/to_id、按 `rel_id(from,to,type)` 重算关系 id、
同步 relation_events 端点；方向相反的重复边（交换后同 id）合并为一条、事件归并。
幂等：重跑只处理仍不合约定的边。

**产出**：`docs/reports/relation-direction-review.md`——判不了的边+弱信号冲突的边，
人工核查后把结论写回脚本顶部结论区再跑（沿 merge_alias_fragments 工作流）。

### 2. novel_kg/trees.py（纯逻辑）

```python
def li_family_members(conn) -> set[str]        # 李家圈定
def build_family_tree(conn, members) -> FamilyTree
def build_master_tree(conn, faction_id) -> MasterTree
def render_dot(tree, title) -> str             # graphviz dot 源码
def render_mermaid(tree, title) -> str         # mermaid graph TD 源码
```

**李家圈定**：以李木田、李根水等早期血脉为种子，沿亲属边（亲子/夫妻/兄弟/祖孙/叔侄/姑侄/舅甥）
做连通闭包，再过滤 `李姓 OR 与血脉成员有夫妻边`——排除李妃若等同姓外人（无亲属边连通者）。
嫁入配偶（田芸/任氏/木芽鹿等）经夫妻边入树。

**族谱树构建**：
- 亲子边拓扑分层定代际；夫妻 `rank=same` 并排（dot 无箭头边）
- **多父冲突**（同一子女有指向两个不同父/母的亲子边，含数据错误）：取首现章早者为主父，
  冲突进报告（stderr+文件），另一边画虚线
- **环**：拓扑残留环→打破（去首现最晚的边）并报告
- **孤儿**（无亲子边但有叔侄/祖孙等其他亲属边）：按边语义推辈分挂入（叔侄=差一辈）；
  仍无定位的按独立小树排在主树旁
- 节点标签 `名字\n[境界·宗门]`；殁者（简介含"身死/陨落/殁"）名字后加†

**师徒树**：成员=所属该势力的全部人物（所属边，天然含多重所属）；收师徒边（任一端∈成员），
from=师在上 to=徒在下分层；外节点（∉成员）虚线框不展开；师兄弟边同层并排。

### 3. scripts/export_tree.py（CLI）

```
.venv/bin/python scripts/export_tree.py 族谱 [--db data/novel.db] [--out data/exports]
.venv/bin/python scripts/export_tree.py 师徒 --faction 青池宗 [--db] [--out]
```

产出三件套：`{名称}.svg`（dot -Tsvg）、`{名称}.png`（dot -Tpng）、`{名称}.md`（mermaid 代码块）。
族谱默认名"李氏族谱"；师徒树名"{势力名}师徒"。圈定结果为空则报错退出。

## 错误处理

- graphviz/dot 缺失：跳过图片只出 Mermaid，stderr 提示安装方式
- 多父/环/孤儿：不中断导出，全部写入 `data/exports/{名称}.issues.md` 供人工回查修库
- 方向修正脚本 dry-run 模式先行（--dry-run 打印不落库）

## 测试策略（tests/test_trees.py）

内存 sqlite 造 fixture（李木田-四兄弟-玄字辈-渊字辈两代+夫妻边+嫁入配偶+一条方向错乱边
+一条重复反向边），断言：
- 圈定含配偶、不含无连通的同姓外人
- 树分层正确（父代在上）、夫妻同层
- 多父/环被报告且不崩溃
- dot/mermaid 输出含关键节点与边
- 方向修正：简介判向、端点交换幂等、重复边合并计数
